# Pelada da Panela

Aplicativo para organizar a pelada de futebol entre amigos, reunir confirmações de presença e acompanhar partidas, resultados e rankings.

## Acesse o aplicativo

[Abra a Pelada da Panela](https://peladadapanela.lovable.app)

## Como colaborar

- Combine com a responsável pelo projeto o objetivo de cada alteração.
- Crie uma branch para suas mudanças e envie um pull request para revisão antes de integrar à `main`.
- Teste as telas e os fluxos afetados, incluindo a experiência no celular.
- Solicite à responsável as configurações necessárias para trabalhar no projeto; nunca inclua senhas, tokens ou credenciais nos commits.
- Mantenha a `main` estável e preserve o histórico de alterações.

A publicação de atualizações deve ser alinhada com a responsável pelo projeto.
